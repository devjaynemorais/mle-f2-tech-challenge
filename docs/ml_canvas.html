Como visualizar este canvas

O browser bloqueia leitura de arquivos locais. Abra um terminal em docs/ e rode:

python -m http.server 8080

Depois acesse: http://localhost:8080/docs/ml_canvas.html

Para editar o conteúdo, modifique ml_canvas.json e recarregue a página.
